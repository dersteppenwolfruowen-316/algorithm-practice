# 03 · 单调栈

## 核心思路

单调栈维护一个**单调递增或递减**的栈，用于快速找到每个元素左/右侧第一个更大或更小的元素。

**时间复杂度：** O(n)，每个元素最多入栈/出栈一次。

---

## 经典问题模式

| 问题类型 | 栈的单调性 | 说明 |
|---------|-----------|------|
| 找右侧第一个更大值 | 单调递减 | 栈顶被弹出时，当前元素就是答案 |
| 找左侧第一个更大值 | 单调递减 | 入栈时栈顶即为答案 |
| 接雨水/最大矩形 | 综合 | 同时维护左右边界 |

**模板：**
```python
stack = []  # 存下标
for i in range(n):
    while stack and nums[stack[-1]] < nums[i]:  # 弹出时处理
        idx = stack.pop()
        # nums[idx] 右侧第一个更大值是 nums[i]
        # 左侧第一个更大值是 nums[stack[-1]]（若栈非空）
    stack.append(i)
```
