# 01 · 滑动窗口

## 核心思路

滑动窗口本质上是「用两个指针维护一段区间」，分两大类：

| 类型 | 特征 | 模板 |
|------|------|------|
| **定长** | 窗口大小 k 固定，平移即可 | 进一个出一个 |
| **不定长** | 窗口按条件伸缩 | 右扩 → 不满足则左缩 |

---

## 定长滑动窗口

> 化繁就简，重点是维护窗口内状态的逻辑，而不是指针本身。

**关键细节：**
- 循环数组（首尾相接）→ 下标取模 `i % n`，循环 `2n` 次
- 遇到字符串：转化为子串问题，从"频率/计数"切入，字符频率类可做到 O(n)
- `range` 是左闭右开；循环次数 = `n` 还是 `n+1` 要想清楚
- 弄清楚初始窗口的左右开闭，以及要维护的元素下标

**经典技巧：**
- **1052 爱生气的书店老板**：先算出不生气时的基础满意度，再用定长窗口找「生气时段的最大收益」

见 [定长/](定长/) 目录（28 题）

## 不定长滑动窗口

> 模世界的运算（来自灵神）

**通用模板：**
```python
left = 0
for right in range(n):
    # 1. 入：将 nums[right] 加入窗口
    window.add(nums[right])
    # 2. 缩：不满足条件时收缩左边界
    while not valid(window):
        window.remove(nums[left])
        left += 1
    # 3. 更新答案
    ans = max(ans, right - left + 1)
```

### 转换思维的核心技巧

**1. 正难则反：求最小 → 求最大**

| 题目 | 思路 |
|------|------|
| 1658 将x减到0的最小操作数 | 从两端删 = 中间留，转化为求和为 `sum(nums)-x` 的**最长子数组** |
| 2516 每种字符至少取k个 | 从两端取 = 中间留，转化为求中间**最长子串**使得两端剩余 ≥k |

**关键：** 涉及「从数组开头和末尾行动」→ 转化为「中间保留最长」，用不定长窗口求中间段

**2. 字符频率类：用 `defaultdict` 维护窗口内计数**

| 题目 | 思路 |
|------|------|
| 1004 最大连续1的个数III | 统计窗口内 0 的个数，`count[0] > k` 时收缩 |
| 2516 每种字符至少取k个 | 窗口内某字符超过 `total[ch] - k` 时收缩 |

**关键：** 维护 `ch_count` 字典，`while` 条件判断是否违反约束

**3. 循环数组：拆成两段 or 复制一遍**

**4. 什么时候滑动窗口出？长度是 n 还是 n+1？**

- 定长窗口：当 `i >= k-1` 时窗口完整，`left = i - k + 1` 开始滑出
- 不定长窗口：`while` 条件决定何时收缩，窗口长度 = `right - left + 1`

见 [不定长/](不定长/) 目录（40 题）

## 单调队列 + 滑动窗口

> 当窗口内需要快速获取 **最大值/最小值** 时，用单调队列将每次操作降到 O(1)。

**核心：** 维护单调递减（求最大）或单调递增（求最小）的双端队列

见 [单调队列+滑动窗口/](单调队列+滑动窗口/) 目录（6 题）

## 双指针 vs 滑动窗口

| | 双指针 | 滑动窗口 |
|---|--------|---------|
| **区别** | 两指针可相向移动 | 两指针同向，维护区间 |
| **何时用双指针** | 有序数组/链表，寻找满足条件的一对元素 | 子数组/子字符串的最优解 |
| **语言扩展** | `sorted` + two-pointer | `collections.deque` 做单调队列 |
