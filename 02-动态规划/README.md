# 02 · 动态规划

## 核心思路

动态规划的本质是「把大问题拆成子问题，用记忆化避免重复计算」。

**三步走：**
1. **定义状态** `dfs(i)` 或 `dp[i]` 代表什么
2. **写出转移方程** `dfs(i) = f(dfs(i-1), ...)`
3. **确定边界条件** 递归出口/初始值

## 线性 DP

### 最大子数组和系列

**核心：** 定义 `dfs(i)` = 以 `nums[i]` 结尾的最大子数组和

| # | 题目 | 要点 |
|---|------|------|
| 53 | 最大子数组和 | `dfs(i) = max(dfs(i-1), 0) + nums[i]` |
| 152 | 乘积最大子数组 | **同时维护最大值和最小值**，处理负数翻转 |
| 918 | 环形子数组的最大和 | 正向最大 + 反向最小，答案取 `max(max_s, sum - min_s)` |
| 1186 | 删除一次得到子数组最大和 | 带删除操作的 Kadane，维护删/不删两个状态 |

**152 关键：** 因为负数 × 负数 = 正数，所以维护 `f_max[i]` 和 `f_min[i]`，下一步取 `max(f_max[i-1]*x, f_min[i-1]*x, x)`

**918 关键：** 环形数组 = 不跨过分界 or 跨过分界，跨过时等价于 `sum(nums) - 最小子数组和`

## 网格图 DP

**核心：** 定义 `dfs(i, j)` = 到达/从 `(i,j)` 出发的最优解

### 路径方案数 / 最小路径和

### 逆向 DP（从终点往起点）

| # | 题目 | 要点 |
|---|------|------|
| 174 | 地下城游戏 | **逆向 DP**：`dfs(i,j)` = 进入 `(i,j)` 时所需的最低血量，保证到终点时 ≥1 |

**174 关键思路：**  
- `dfs(i,j)` = 进入房间 `(i,j)` 时，为了能安全走完剩下的路径（到达终点时血量 ≥1）所需的最低血量
- 从终点倒推：`need = min(dfs(i+1,j), dfs(i,j+1)) - dungeon[i][j]`，再 `max(1, need)` 保证不死

## 0-1 背包

**核心：** 选或不选，容量约束下求最优解

**状态定义：** `f[j]` = 容量 `j` 时的最大价值  
**转移方程：** `f[j] = max(f[j], f[j-w] + v)`（**倒序遍历容量**）  
**空间优化：** 滚动数组，一维即可

### 经典变形

| # | 题目 | 要点 |
|---|------|------|
| 416 | 分割等和子集 | 是否能装满 `sum/2` |
| 474 | 一和零 | **二维费用背包**：`f[i][j]` 同时约束 0 和 1 的个数 |
| 3946 | 购买最多物品数目 I | **0-1背包 + 枚举**：`f[j]` 记录买了 factor 倍数的物品个数，最后 `max(f[i] + (budget-i)//min_price)` |

**3946 关键思路：**  
- 对每个 `factor`，统计有多少物品的 `factor_j` 是它的倍数，这些是「一组」
- 背包记录：花费 `j` 预算时最多买多少个这样的物品
- 最后枚举剩余预算，用最便宜的物品填满：`f[i] + (budget-i)//min_price`

见 [0-1背包/](0-1背包/) 目录（5 题）

## 记忆化搜索

> DFS + `@cache` = DP

**适用场景：** 状态定义复杂、转移不规则、树形依赖

**Python 模板：**
```python
from functools import cache

@cache
def dfs(i, ...):
    if 递归出口:
        return ...
    return max(dfs(下一个状态) for ...)
```

包含：数位DP、状态机、贪心+DP

## 0-1 BFS

> 边权只有 0 和 1 的最短路，用**双端队列**代替普通队列

**核心思想：**
- 权值 0 的边 → `dq.appendleft(v)`（插队首）
- 权值 1 的边 → `dq.append(v)`（插队尾）
- 保持队列单调性，每个节点最多入队一次
