# 02 · 动态规划

## 核心思路

动态规划的本质是「把大问题拆成子问题，用记忆化避免重复计算」。

**三步走：**
1. **定义状态** `dp[i]` 代表什么
2. **写出转移方程** `dp[i] = f(dp[i-1], ...)`
3. **确定边界条件** 初始值

## 单调队列优化DP

> 当转移方程形如 `dp[i] = max(dp[j]) + cost`，且 j 在滑动窗口内时，
> 用单调队列把 O(n²) 优化到 O(n)。
