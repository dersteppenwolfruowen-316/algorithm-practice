# 0-1 背包

## 核心骨架

```python
for 物品 in 物品们:              # 外层：物品
    for 容量 in range(V, w-1, -1):  # 内层：容量，倒序
        dp[容量] = f(dp[容量], dp[容量 - w])
```

**三要素配套：**
- **外层物品**：`dp` 的含义是"处理完前 k 个物品后的状态"
- **内层容量**：每轮对所有容量更新一遍
- **倒序**：保证 `dp[容量-w]` 是上一轮（还没放当前物品）的值，每个物品至多用一次

---

## 问法变化 → 转移/初始化/答案位置

| 问法 | `dp[i]` 含义 | 初始化 | 转移 | 答案 |
|---|---|---|---|---|
| 最大价值（不超过） | 容量不超过 `i` 的最大价值 | 全 0 | `max(dp[i], dp[i-w]+v)` | `dp[V]` |
| 最大价值（恰好装满） | 恰好装满 `i` 的最大价值 | `dp[0]=0`，其余 `-inf` | 同上 | `dp[V]` |
| 最少个数（恰好） | 凑出 `i` 的最少物品数 | `dp[0]=0`，其余 `inf` | `min(dp[i], dp[i-w]+1)` | `dp[V]` |
| 能否凑出 | 能否恰好凑出 `i` | `dp[0]=True`，其余 `False` | `dp[i] \|= dp[i-w]` | `dp[V]` |
| 方案数 | 凑出 `i` 的方案数 | `dp[0]=1`，其余 0 | `dp[i] += dp[i-w]` | `dp[V]` |

**"不超过" vs "恰好"：**
- **不超过**：初始全 0 成立（什么都不选，任何容量价值都是 0）
- **恰好**：非 0 容量初始不可达，用 `-inf` 或 `inf` 标记，否则会把不可能的状态当成可行解

## 多维背包：一个约束一维

每多一个限制条件就多一维，**每一维都倒序**。

### 示例：879 盈利计划

**限制：** 人数 ≤ n（不超过）+ 利润 ≥ minProfit（至少）  
**定义：** `dp[j][k]` = 用至多 `j` 人、利润至少 `k` 的方案数

```python
MOD = 10**9 + 7

def profitableSchemes(n, minProfit, group, profit):
    dp = [[0] * (minProfit + 1) for _ in range(n + 1)]
    for j in range(n + 1):
        dp[j][0] = 1                      # 空计划：利润至少0，人数≤j
    
    for g, p in zip(group, profit):       # 外层：工作（物品）
        for j in range(n, g - 1, -1):     # 人数，倒序
            for k in range(minProfit, -1, -1):  # 利润，倒序
                dp[j][k] = (dp[j][k] + dp[j - g][max(0, k - p)]) % MOD
    
    return dp[n][minProfit]
```

**关键点：**
- 人数是"不超过"，范围 `g..n`
- 利润是"至少"，读取 `max(0, k - p)`（负数截断为 0）
- 求方案数，转移用 `+=`，初始化 `dp[j][0] = 1`

---

## "至少"类问题的处理

利润可以无限大，无法直接用利润当下标，两种方案：

1. **截断**：超过 `minProfit` 的都当成 `minProfit`，即 `min(minProfit, k + p)`
2. **改定义**：`dp[..][k]` = 利润**至少** `k` 的方案数，转移时负数取 0：`max(0, k - p)`

第二种更方便，写成"从小下标读取"。

## 外层容量内层物品？

**不行。** 0-1 背包若换成外层容量、内层物品，同一个容量格会被多个物品连续更新，状态里不再保证"每个物品只处理一次"。

顺序的选择只在**完全背包的计数题**里才有意义：
- 外层物品 → 组合数
- 外层容量 → 排列数

**0-1 背包只有"外层物品"这一种写法。**

## 写题检查清单

1. **物品是什么？** 每个物品有哪些"消耗"？每个消耗就是一个维度
2. **每个维度是"不超过 / 恰好 / 至少"？** 决定初始化和最后读哪一格
3. **求什么？** 最值用 `max/min`、可行性用 `or`、方案数用 `+`
4. **外层物品，内层各维度倒序**
5. **方案数题别忘了取模**
