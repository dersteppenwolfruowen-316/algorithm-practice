## 通用复杂度备忘

| 操作 | 数据结构 | 时间复杂度 |
|------|---------|-----------|
| 滑动窗口最值 | 单调队列 deque | O(1) 均摊 |
| 动态规划窗口最值 | 单调队列优化 | O(n) |
| 下一个更大元素 | 单调栈 | O(n) |
| 区间和查询 | 前缀和 | O(1) 查询 |
| 0-1 背包 | 滚动数组优化 | O(nW) 空间降至 O(W) |

> **解决空间复杂度：用合适的数据结构代替暴力枚举。**
